mobie Hackathon Starter

Sign in once with your staging test passenger account. The server refreshes the access token automatically.

Each server process uses one test passenger account. All phone calls through this starter use that account.



After signing in, enter your team key again and check the API connection. The key is not stored in the browser.

See the README and docs/api.md in your repository for documentation and example requests.

Tokens stay in memory. You must sign in again after restarting the server.
